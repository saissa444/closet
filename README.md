# 財產清冊（原「生活帳本」「衣櫥帳本」）

衣櫥、電器、物品三本帳：建檔、盤點、花費統計、保固與效期提醒、淘汰紀錄。
資料（含照片、發票）只存在你自己的裝置裡，不會上傳。

網址：https://saissa444.github.io/closet/

## iPhone 使用
- 用 Safari 開網址 → 分享 →「加入主畫面」，之後都從主畫面圖示開。
- Safari 分頁和主畫面 App 的資料是分開的，請固定用主畫面那個。
- **刪掉主畫面圖示，資料會一起被刪除。** 刪之前一定要先到「設定 → 匯出備份」。

## 想讓主畫面名稱變成「財產清冊」
App 打開後已經是新版和新名稱；主畫面圖示下的字要重新加入才會變：
1. 打開舊的主畫面 App →「設定」→「匯出備份」→ 存到「檔案」。
2. 確認備份檔有存好，再長按舊圖示 → 刪除 App。
3. 用 Safari 開網址 → 分享 →「加入主畫面」。
4. 打開新圖示 →「設定」→「匯入備份」→ 選剛剛的檔案 →「合併」。
不重新加入也沒關係，只是主畫面圖示下的字會維持舊名稱。（加入主畫面時，名稱欄位也可以自己改。）

## 換機／在電腦上看
設定 →「匯出備份」產生一個 `.json` 檔（含所有照片）→ 傳到另一台 → 設定 →「匯入備份」→ 選「合併」或「全部取代」。
建議每個月匯出一次。超過 30 天沒備份時，「設定」會出現紅點提醒。

## 之後要更新 App
修改 `index.html` 後，把 `sw.js` 第二行的版本號 +1（例如 `closet-v7` → `closet-v8`），再上傳覆蓋。你的資料不會受影響。
